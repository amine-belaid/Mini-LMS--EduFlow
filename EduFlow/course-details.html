À propos de ce cours

Ce cours vous permettra d’apprendre les bases du développement web avec HTML et CSS. Vous découvrirez comment structurer une page web, la styliser avec CSS, et créer un site moderne et responsive. À la fin du cours, vous réaliserez un projet complet.

◎

Ce que vous allez apprendre

  • Comprendre la structure d’une page HTML.
  • Utiliser les balises HTML principales (head, body, div, p, h1, ...).
  • Styliser vos pages avec CSS (couleurs, polices, mise en page).
  • Créer un design responsive pour tous les écrans.
  • Réaliser un projet web complet de A à Z.
🎓

Prérequis

  • Aucune connaissance préalable en programmation n’est nécessaire.
  • Un ordinateur avec un navigateur web (Chrome, Firefox, etc.).
